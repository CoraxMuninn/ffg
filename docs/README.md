# Feiz Food Group — documentation

Operational documents for running and maintaining the site. Historical audit
notes, completed-phase reports, and pre-implementation specs were removed
during the production slimming pass; this index is the remaining set.

| Document | What it covers |
|---|---|
| `DEPLOYMENT.md` | Authoritative production topology — single Node process behind Nginx on a VPS, supervised by systemd. Environment, health, and security contract. |
| `CMS-ADMIN-SETUP.md` | Decap CMS setup, editorial workflow, self-hosted runtime, least-privilege OAuth. `config.yml` is generated by `scripts/generate-cms-config.mjs`. |
| `SLUG-POLICY.md` | Localized-slug decision: retain stable English shared slugs. |
| `PERFORMANCE.md` | Bundle / Lighthouse budgets and the RUM decision gate. |

Root `README.md` is the project overview. Environment variables are documented
in `.env.example`.

Production is a **VPS** (Nginx + systemd), **not** a platform-as-a-service
build pipeline.
