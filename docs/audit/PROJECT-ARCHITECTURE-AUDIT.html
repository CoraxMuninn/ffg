12 Risk Analysis
Biggest risks across architecture, business, UX, SEO, and security
Critical

🏗️ Biggest Architectural Risk

No i18n routing foundation. Every page, link, metadata entry, and SEO element depends on the locale routing structure. Building pages without this foundation means they must be rebuilt when i18n is added. This is the single most important architectural decision to make before building any pages.

Critical

💼 Biggest Business Risk

No RFQ infrastructure. The primary business objective — generating qualified quotes from international buyers — has zero implementation. Every visitor who wants to request a quote hits a 404 page. This is a complete business failure point.

High

📱 Biggest UX Risk

Non-functional language switcher. The header presents a language selector with 4 languages as a core navigation element. When a user selects "فارسی", nothing happens. This creates a broken expectation and undermines trust in the site's international capability — which is central to the business.

High

🔍 Biggest SEO Risk

No multilingual SEO infrastructure. The documentation specifies hreflang, x-default, localized metadata, sitemap across locales, and localized schema. Without any of this, the site cannot rank in any language market. For a business whose primary market (Vietnam) requires Vietnamese SEO, this is a critical gap.

High

🔒 Biggest Security Risk

No security headers and no API security foundation. When the RFQ API is built, it will be a public-facing endpoint accepting user input and sending email. Without rate limiting, input validation, CSP, and security headers in place from the start, this will be a high-value attack target. Security must be built in, not bolted on.

Medium

⚠️ Documentation/Code Conflict

Market page structure. Documentation says "one Markets page." Code links to individual market pages (/markets/vietnam, etc.). This conflict must be resolved before implementation.

Medium

🎨 Design System Drift

Primary CTA color. Documentation says Midnight Navy. Code uses Cyan 600 throughout. This affects every button in the system and must be resolved before building the design system.

Medium

🖼️ Placeholder Images

generate-placeholders.js creates placeholder images. It is unclear whether the current images are placeholders or final. Real industrial imagery is required per the design specification.
